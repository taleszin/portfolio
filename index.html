04 · Baixo nível

Um tablet de 2014 que ia pro lixo virou um sistema operacional.

O Multilaser M7s tem 512 MB de RAM, dois núcleos a 1 GHz e nenhuma ROM alternativa no mundo. Escrevi a primeira: o Taleszin OS, com build reproduzível a partir do firmware oficial, serviços de boot em shell, hooks na interface do Android e cinco apps nativos feitos sem Gradle. Tudo pelo cabo USB, sem abrir o aparelho.

m7s-botao · sh

# evdev cru: struct input_event de 16 bytes
set -- $(dd bs=16 count=1 <&3 | od -b)
# type 001 = EV_KEY · code 164 = KEY_POWER
[ "${10}${11}" = 001000 ] || continue
# segurou 8 s: sync, só-leitura, reboot
echo s > /proc/sysrq-trigger
echo u > /proc/sysrq-trigger
echo b > /proc/sysrq-trigger
  1. 01

    Hardware e gravação

    Rockchip RK3026, NAND e partições mapeadas por engenharia reversa do firmware oficial. Backup completo em modo loader e gravação pelo Mac com rkflashtool, com conferência por sha256 bloco a bloco.

  2. 02

    Kernel e drivers

    O sensor de bateria do kernel congela entre degraus de porcentagem, então a tensão real vem do ADC lido direto (× 6,06 mV). O botão liga/desliga é lido como evento cru do evdev e, segurado por 8 s, força um reinício limpo via sysrq, um reset que o aparelho não tinha.

  3. 03

    Boot e serviços

    Serviços em shell que sobem no init: zRAM de 128 MB, KSM, governador de CPU ajustado, uma sentinela que mata o processo certo antes do travamento por falta de memória, caixa-preta que explica no boot seguinte por que a sessão anterior acabou e um vigia de bateria em degraus.

  4. 04

    Sistema e interface

    system.img reproduzível a partir do zip oficial, sem versionar firmware nem APK de terceiros. Hooks em Xposed na SystemUI para trocar o layout de tablet pelo de celular, contextos de SELinux corrigidos para o hook carregar e animação de boot própria.

  5. 05

    Apps nativos

    Tela inicial, tema, Diagnóstico, leitor de livros Estante (paginação em colunas numa WebView de 2013) e Fliperama, que abre jogos homebrew direto no emulador. Java puro, compilado com aapt2 e d8 sem Gradle: a maioria dos apps tem menos de 120 KB.

  • 512 MBde RAM, com zRAM e KSM para caber
  • 0ROMs alternativas antes desta para o aparelho
  • 0apps nativos próprios, nenhum com Gradle
  • 0 fpsno Super Nintendo, com um shim de compatibilidade para o emulador
